# 스킬 노출 구조: 2차 실험 공개 집계

## 요약

주 모델의 H-flat 정밀도는 94.1% [90.6, 96.9], 재현율은 98.8% [97.4, 99.8]다. 요청 128개를 구조마다 3회 평가한 결과다. H-flat만 채택 기준을 모두 통과했다. 저장소는 짧은 description을 평평하게 노출하고 선택한 본문과 조건부 참조를 읽는 방식을 사용한다.

## 방법

이 문서는 이미 수행한 실험에서 확인한 수치와 판정 기준을 공개용으로 정리한 집계다. 이번 문서 작업에서 모델을 다시 호출하지 않았다. 입력은 [공개 집계](data/aggregates.json), 표와 그림의 정본은 [summary.json](results/summary.json)이다.

| 항목 | 값 |
|---|---|
| 스킬 | 27개 |
| 주 모델 | gpt-5.6-luna, reasoning low |
| 확인 모델 | gpt-6-astra, reasoning low |
| 요청 | 후보 160개, 두 라벨러 합의 135개, 평가 선택 128개 |
| 확인 부분집합 | 같은 요청 중 16개 |
| 반복 | 요청·구조·모델마다 3회 |
| 조건 | 대조, flat, tree, hybrid |
| 보고 구간 | 요청 군집 bootstrap 10,000회, 95% |
| 판정 구간 | 후보 선택의 다중 비교 보정, 98.333% 동시 구간 |
| 집계 시드 | 20261005 |
| 설계 봉인 | 2026-10-03T23:53:33Z, SHA-256은 집계 provenance |

정밀도는 TP/(TP+FP), 재현율은 TP/(TP+FN)으로 계산했다. TP는 정답과 읽은 스킬의 교집합, FP는 불필요하게 읽은 스킬, FN은 필요한데 읽지 않은 스킬이다. 반복을 독립 표본으로 취급하지 않고 같은 요청의 반복과 조건을 함께 재표집했다.

## 설계와 다른 점

원래 실험의 설계는 Git 커밋 대신 SHA-256으로 봉인했다. 수집 과부하로 미실행 평가를 한 번 재개했으며, 중단된 평가는 실패로 유지했다. 집계 단계에서 중단된 실행의 예정 읽기 집합을 실제 전송 집합으로 재구성했다. 원자료의 평가 응답은 바꾸지 않았다.

공개본에는 요청 본문, 모델 응답, 로컬 도구의 노출 로그를 포함하지 않는다. 집계 원본의 SHA-256, 평가 개수, 혼동 개수, 신뢰구간과 채택 판정을 선별해 보존했다. 공개 스크립트는 정밀도·재현율 산술과 그림 입력을 재현한다. 원자료부터 bootstrap 구간을 다시 계산하거나 모델 평가를 재실행하는 패키지는 아니다.

### 판정

후보가 다음 기준을 모두 통과해야 채택했다. 품질 하락 허용 경계는 5%p였다. flat/control, tree/flat, hybrid/flat의 목록·전체 읽기·왕복·지연을 비교했고, 각 후보는 대조 대비 품질 기준도 통과해야 했다.

| 기준 | 채택 조건 |
|---|---|
| 정밀도·재현율·정확 집합·일관성 | 차이 동시 구간 하한 > -5%p |
| 과호출·연결 누락 | 차이 동시 구간 상한 < +5%p |
| 목록 읽기량 | 비율 동시 구간 상한 ≤ 0.75 |
| 본문 포함 읽기량 | 비율 동시 구간 상한 ≤ 1.05 |
| 왕복 | 추가 왕복 동시 구간 상한 ≤ 1.1회 |
| 지연 | 비율 동시 구간 상한 ≤ 1.5 |
| hybrid 추가 목적 | tree 대비 연결 누락 차이 동시 구간 상한 < 0 |
| 확인 모델 | 동일 부분집합의 품질 하락 점추정 ≤ 5%p, hybrid 연결 차이 방향 유지 |
| 완결성과 적용 가능성 | 계획 평가 기록, 원자료 검사, 도구별 숨김·본문 접근 확인 |

| 후보 | 판정 | 미통과 기준 |
|---|---|---|
| H-flat | 채택 | 없음 |
| H-tree | 보류 | 재현율, 정확 집합, 일관성, 연결 누락, 대조 대비 품질 |
| H-hybrid | 보류 | 일관성, 연결 누락, 목록 읽기량, 대조 대비 품질, 연결 개선 |

H-flat은 목록을 5,547바이트에서 3,336바이트로 줄였다. 목록 비율은 0.6014다. 대조 대비 재현율 차이의 동시 구간은 [-0.562, 1.267]%p로 비열등 경계를 통과했다. 정밀도 점추정이 더 높은 구조도 다른 기준을 통과하지 못하면 채택하지 않았다.

## 논의

보류는 열등함의 입증이 아니다. 후보 비교를 보정한 뒤 일관성 검정에 필요한 요청은 569~775개로, 이번 128개보다 많다. 두 모델의 합의는 인간 정답 검증이 아니며 같은 모델 계열의 편향이 남는다. 합의하지 않은 요청을 제외하면 어려운 경계 요청이 빠질 수 있다.

이 실험은 제한된 카탈로그와 본문 전달 횟수에서 스킬 선택을 평가했다. 실제 코드 수정·문서 작성의 품질, 전체 설치 환경과 자연스러운 작업의 끝까지 실행을 검증하지 않았다. 1차 실험과 요청 분포도 달라 전후 수치를 구조 효과로 단정하지 않는다.

## 재현

```sh
python3 experiments/skill-exposure/scripts/03-analyze.py
```

같은 입력에서 summary.json을 다시 생성한다. 스크립트는 모든 구조·모델의 혼동 개수로 정밀도·재현율을 대조하고, 주 모델의 차트 배열을 생성한다. [그림 재현 안내](../../docs/assets/README.md)의 명령으로 SVG를 만든다.

## 결론

H-flat을 채택해 [README](../../README.md#작동-방식)에 반영했다. tree와 hybrid는 보류 상태이며, 이번 결과를 두 구조가 항상 나쁘다는 근거로 사용하지 않는다.
