# 읽은 스킬

1. repo-docs: 카탈로그의 저장소 문서 공통 규칙, 종류별 스킬의 기반(과제 1)
2. repo-docs-design: `docs/architecture.md` 템플릿(과제 1)
3. repo-docs-readme: 루트 `README.md` 템플릿과 단계 판정(과제 2)
4. repo-docs-decision: 비공개 판단 기록을 공개 결정 기록으로 다시 쓰기(과제 3)
5. repo-docs-journal: repo-docs-decision의 필요할 때만 읽기, 비공개 판단 기록에서 옮길 때(과제 3)
6. repo-docs-root: `AGENTS.md` 템플릿(과제 4)
