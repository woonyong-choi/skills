# 읽은 스킬

1. repo-docs: 저장소 문서 작업 전 먼저 적용하는 공통 규칙과 `check_doc` 함수
2. repo-docs-design: `docs/architecture.md` 템플릿과 절 규칙
3. repo-docs-readme: 루트 `README.md` 템플릿, 단계 판정, 기능과 로드맵 구분
4. repo-docs-decision: 비공개 판단 기록을 공개 결정 기록으로 다시 쓰는 규칙
5. repo-docs-journal: repo-docs-decision의 필요할 때만 읽기 조건(비공개 판단 기록에서 옮기기)과 판단 기록 표시 뜻
6. repo-docs-root: `AGENTS.md` 템플릿과 `CLAUDE.md` 링크 규칙

- 읽지 않은 스킬: repo-docs-figures(그림 불필요, 그림 파일 없음), repo-docs-spec, repo-docs-llms(`docs/README.md` 없음)
