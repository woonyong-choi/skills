## 배경

엔진이 공급자 CLI와 어떤 통로로 통신할지 정해야 했다. 공급자마다 연결 코드를 따로 두지 않는 통로가 필요했다. Codex CLI와 Claude Code CLI는 모두 stdio JSON 스트림 모드를 제공했다(2026-09-20 확인). 소켓 모드는 Codex CLI만 제공했다(2026-09-20 확인).

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| stdio | 두 공급자 공통, 자식 프로세스 수명과 연결 수명 동일 | 원격 공급자 불가 |
| Unix 소켓 | 공급자 별도 실행 가능 | Claude Code 미지원 |
| TCP | 원격 가능 | 인증 필요, 두 공급자 모두 미지원 |

## 결정

stdio를 골랐다. 두 공급자가 모두 지원하는 유일한 통로라는 점이 기준이었다.

## 결과

- 두 공급자 공통 통로
- 자식 프로세스 수명과 연결 수명 동일
- 원격 공급자 불가

## 다시 볼 조건

- 공급자의 stdio 모드 제거
- 사용자의 원격 공급자 실행 요청
