# Repo Docs Promo

- 저장소 안에 같은 역할의 규칙이 있으면 그것 우선. 없으면 이 스킬이 다른 규칙보다 우선
- 기반: repo-docs 먼저 적용. 이 스킬 범위: 저장소 밖에서 쓰는 홍보 영상의 촬영 준비물

- 녹화, 편집: 사용자가 화면 녹화 앱으로 직접. 에이전트의 녹화 앱 조작 금지
- README와 docs의 데모 GIF: VHS(repo-docs-figures), 이 스킬 대상 밖
- 위치: 비공개 폴더 `.local/promo/{영상}/`. `{영상}`은 영어 소문자 kebab-case 2~5단어

## 폴더

```text
.local/promo/{영상}/
  shot.md
  demo.command
  go
```

| 파일 | 내용 |
|---|---|
| `shot.md` | 촬영 순서표와 내보내기 규격 |
| `demo.command` | 합성 데이터로 저절로 재생되는 데모 스크립트 |
| `go` | 재생 신호 파일. 녹화 시작 뒤 생성, 스크립트가 읽고 삭제 |

## shot.md

```text
# {영상 제목}

| 항목 | 값 |
|---|---|
| 쓰는 곳 | {랜딩 페이지, 링크드인, 블로그} |
| 보여 줄 결론 | {보는 사람이 알게 될 것 한 문장} |
| 길이 | {초}초 |
| 화면 비율 | {16:9, 1:1} |
| 데이터 | {실제, 합성 데이터} |

## 장면

| 순서 | 화면 | 동작 | 길이 | 자막 |
|---|---|---|---|---|
| 1 | {보이는 화면} | {일어나는 일} | {초}초 | {자막, 또는 없음} |

## 내보내기

| 파일 | 형식 | 크기 |
|---|---|---|
| `{영상}-{비율}.mp4` | MP4, 소리 없음 | {가로}×{세로} |
```

| 자리 | 규칙 |
|---|---|
| 보여 줄 결론 | 기능 하나. README 기능 절이나 `docs/design/` 문서 제목에 있는 것만 |
| 길이 | 랜딩 페이지 15~30초, 링크드인 30~60초, 블로그 60초 이내 |
| 화면 비율 | 랜딩 페이지와 블로그 16:9, 링크드인 1:1 |
| 장면 | 3~6개. 자막은 20자 이내 명사구 |
| 데이터 | 로드맵 상태 기능이 화면에 보이면 합성 데이터 |
| 내보내기 크기 | 16:9는 1920×1080, 1:1은 1080×1080 |

## demo.command

```sh
#!/bin/bash
# 합성 데이터 데모. 실제 실행이 아니다.
cd "$(dirname "$0")"
printf '\e]0;{이름}\a'
printf '\e[8;{줄};{칸}t'
clear
while [ ! -f go ]; do sleep 0.2; done
rm -f go
sleep 1
type_out() { local s="$1"; for ((i = 0; i < ${#s}; i++)); do printf '%s' "${s:$i:1}"; sleep 0.06; done; }
printf '$ '; type_out '{명령}'; printf '\n'
{장면별 출력}
sleep 4
```

- 화면에 `합성 데이터` 글자 한 번 이상 노출
- 창 제목을 `{이름}`으로 변경. 창 제목과 화면에 사용자 이름, 홈 경로, 키, 실제 사용자 데이터 노출 금지
- 장면 순서와 길이: `shot.md` 장면 표 기준
- 저장 뒤 `chmod +x demo.command`로 실행 권한 부여. 권한을 바꾸는 편집 뒤에도 재확인
- 스크립트: `go` 파일이 생길 때까지 대기(녹화를 먼저 시작하기 위해)

## 촬영 순서

사용자에게 아래 순서 안내:

1. 사용자: Finder에서 `demo.command` 실행. 터미널 창이 열리고 빈 화면에서 정지
2. 사용자: 화면 녹화 앱에서 그 터미널 창을 녹화 대상으로 골라 녹화 시작
3. 에이전트나 사용자: `.local/promo/{영상}/go` 파일 생성. 데모 재생
4. 사용자: 재생이 끝나면 녹화 중지, 확대와 배경 편집, `shot.md` 내보내기 표대로 저장

- 키보드로 다루는 터미널 화면은 커서 추적 자동 확대가 거의 없음. 확대는 편집에서 장면마다 직접 넣도록 안내

## 확인

사용자가 내보낸 파일을 받으면 아래 항목 확인:

1. 길이와 크기가 `shot.md`와 일치
2. `합성 데이터` 글자 노출(데이터가 합성 데이터일 때)
3. 사용자 이름, 경로, 알림, 다른 앱 창 미노출
4. 자막과 화면 글자에 쓰지 않는 말(repo-docs 용어 표) 없음
