# 검토

검토자: 작성 결론 전제 금지, diff·계약·시험 증거 직접 대조. 검토 역할·입력과 발견별 근거 기록. 규칙·설계 두 축의 독립 검토

축 → 기준 → 보는 것:

- 규칙 → 저장소 규칙, code-style과 언어별 스킬 → 이름, 구조, 오류 처리, 테스트, 금지 항목
- 설계 → 이슈 완료 조건, 설계 문서 → 빠진 조건, 범위 밖 변경, 설계와 다른 동작, 문서 동반, 가정 절, 화면·움직임 수용표(머지 조건)

검토 댓글

```text
## 규칙 검토
- 필수 · {파일·항목}: {문제} ({근거 규칙})
- 제안 · {파일·항목}: {문제}

## 설계 검토
- 필수 · {완료 조건·설계 절}: {문제}
```

- 발견이 없으면 그 절에 `발견 없음`
- `필수`만 머지 차단. `제안`은 작성자 판단
- 취향, 근거 규칙을 댈 수 없는 지적 기록 금지
