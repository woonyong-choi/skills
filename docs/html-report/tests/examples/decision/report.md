질문 1개. 목차 위치는 A를 추천. 질문마다 버튼으로 고른 뒤 결과 복사를 눌러 붙여 넣으면 진행

## 목차 위치

긴 문서에서 목차를 어디에 둘지 고르기. 지금은 본문 오른쪽에 고정

```ui:figure-grid
{ "columns": 2, "items": [
  { "src": "a.png", "alt": "목차가 본문 오른쪽에 계속 보인다", "caption": "오른쪽 고정 (지금)" },
  { "src": "b.png", "alt": "목차가 본문 위에 접혀 있다", "caption": "본문 위 접기" }
] }
```

비교 기준: 지금 읽는 위치 찾기, 다른 절로 건너뛰기

**A. 오른쪽 고정**

- 보이는 모습: 스크롤해도 목차가 오른쪽에 그대로 있음
- 좋아지는 것: 다른 절로 바로 건너뛰기. 예: 12개 절 문서에서 "정리"를 한 번에 누름
- 불편해지는 것: 본문 폭 줄어듦. 예: 1555px 화면(노트북 전체 폭)에서 본문 폭 3분의 2

**B. 본문 위 접기**

- 보이는 모습: 목차가 제목 아래 한 줄로 접혀 있음
- 좋아지는 것: 본문 폭 전부 사용. 예: 코드 블록 줄바꿈 0줄
- 불편해지는 것: 지금 읽는 위치 찾기. 예: 8번째 절에서 목차를 보려면 맨 위로 올라감

:::note[추천]
A. 긴 문서에서 지금 읽는 위치가 계속 보임
:::

## 정리

- 목차 위치: A 추천
