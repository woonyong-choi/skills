세션이 끝나도 다음 세션이 같은 작업을 이어받도록 작업 기록을 남깁니다.

## 세션이 끝날 때 기록이 남습니다

- 한 줄로: 세션을 닫기 전에 지금 상태를 이슈 댓글로 남깁니다.
- 예를 들면: 이슈 #96에 "다음: 시험 실행"이라는 댓글이 생깁니다.
- 이게 없으면: 새 세션이 어디까지 했는지 몰라 처음부터 다시 읽습니다.

그림에서는 세션, 훅, 이슈 댓글 순서로 상태가 옮겨 가는 것을 봅니다.

```thinkflow
thinkflow
title "작업 기록이 남는 경로"
box session "세션"
box hook "훅"
store record "이슈 댓글"
session -> hook "상태"
hook -> record "저장"
```

## 새 세션은 댓글부터 읽습니다

- 한 줄로: 새 세션은 시작하자마자 마지막 댓글을 읽고 이어서 합니다.
- 예를 들면: 댓글의 "다음: 시험 실행"을 보고 바로 시험부터 돌립니다.
- 이게 없으면: 같은 파일을 두 번 고치거나 끝난 일을 다시 합니다.

## 정리

작업 기록은 세션이 바뀌어도 할 일이 끊기지 않게 합니다. 여러 사람이 같은 이슈를 동시에 맡는 경우는 다루지 않습니다.
