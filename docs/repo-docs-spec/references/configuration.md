# configuration.md

`docs/configuration.md`를 쓰거나 갱신하거나 검토할 때 이 틀을 쓴다. 아래는 TOML 설정의 예이고, 실제 형식과 코드의 설정 우선순위로 바꿔 쓴다.

````text
# 설정

## 우선순위

1. 명령 옵션
2. 환경 변수
3. 프로젝트 설정 파일 `{경로}`
4. 사용자 설정 파일 `{경로}`
5. 기본값

## 항목

### `[{표 이름}]`

| 키 | 타입 | 기본값 | 환경 변수 | 뜻 |
|---|---|---|---|---|
| `{키}` | `{타입}` | `{기본값}` | `{환경 변수}` | {뜻} |

## 전체 예

```toml
{기본값을 모두 적은 설정 파일}
```
````

- 작업 언어가 영어인 저장소는 `설정`을 `Configuration`, `우선순위`를 `Precedence`, `항목`을 `Settings`, `전체 예`를 `Full example`로 쓴다.
- 우선순위는 실제 코드의 적용 순서와 대조한다. 해당하지 않는 단계는 지우고, 순서를 고친 뒤 번호를 다시 매긴다.
- 표 이름은 설정 파일에 나오는 순서로, 키는 알파벳순으로 놓는다.
- 환경 변수가 없으면 `없음`으로 쓴다.
- 전체 예에는 기본값과 같은 값만 쓴다.
