# ui.md

`docs/ui.md`를 쓰거나 갱신하거나 검토할 때 이 틀을 쓴다.

````text
# 화면

## 화면 구성

```text
{화면 구성 그림}
```

## 영역

| 영역 | 보이는 것 | 갱신 시점 |
|---|---|---|
| {영역} | {보이는 것} | {갱신 시점} |

## 키 조작

| 키 | 동작 | 적용 영역 |
|---|---|---|
| `{키}` | {동작} | {영역} |

## 상태 표시

| 표시 | 뜻 |
|---|---|
| `{표시}` | {뜻} |
````

- 작업 언어가 영어인 저장소는 `화면`을 `Interface`, `화면 구성`을 `Layout`, `영역`을 `Regions`, `키 조작`을 `Keys`, `상태 표시`를 `Status indicators`로 쓴다.
- 화면 구성 그림의 상자는 `┌─┐│└┘`로 그리고, 영역 이름은 영역 표와 같은 글자로 쓴다.
- 영역은 위에서 아래, 왼쪽에서 오른쪽 순서로 놓는다.
- 키는 `Ctrl+C`, `Enter`, `Esc`, `Tab`, `↑`처럼 쓴다. 적용 영역 순서로 놓고, 같은 영역 안은 알파벳순으로 놓는다.
