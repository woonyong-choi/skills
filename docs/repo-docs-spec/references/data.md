- 작업 언어가 영어인 저장소는 `데이터`를 `Data`, `저장 방식`을 `Storage`, `관계`를 `Relationships`, `테이블`을 `Tables`, `지켜야 할 규칙`을 `Invariants`, `보관 기간`을 `Retention`, `스키마 변경`을 `Schema changes`, `파일`을 `Other files`로 쓴다.
- 관계 그림은 repo-docs-figures를 따른다.
- 테이블은 관계 그림에서 부모를 먼저 놓는다.
- 문장으로 쓰는 열은 `지켜야 할 규칙`의 `조건`과 `지키는 방법`이다.
- 스키마 변경 절은 `스키마는 앞으로만 바꾼다.`, `버전마다 변경 스크립트 하나를 둔다.`, `시작할 때 저장된 버전보다 높은 변경만 실행한다.`로 쓴다. 규칙이 다르면 이 형식으로 바꿔 쓴다.
- 파일 절은 데이터베이스 밖에 영속 파일이 있을 때만 둔다.
