# errors.md

`docs/errors.md`를 쓰거나 갱신하거나 검토할 때 이 틀을 쓴다.

```text
# 오류

프로세스 종료 코드는 [명령](cli.md)에 있다.

## 오류 코드

| 코드 | 이름 | 메시지 | 원인 | 대응 |
|---|---|---|---|---|
| `{코드}` | `{이름}` | `{메시지}` | {원인} | {대응} |
```

- 작업 언어가 영어인 저장소는 `오류`를 `Errors`, `오류 코드`를 `Error codes`로 쓴다.
- 종료 코드 문장은 `cli.md`가 있을 때만 쓴다.
- 코드는 오름차순으로 놓는다.
- 메시지는 코드의 메시지 문자열 그대로 쓴다.
- 문장으로 쓰는 열은 `원인`, `대응`이다.
- 없앤 코드는 행을 지우지 않고 `이름`을 `폐기`로 바꾼다. 없앤 코드를 다시 쓰지 않는다.
