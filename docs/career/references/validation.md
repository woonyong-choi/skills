# 검증

확인 단계·실패 수정 때 적용. 확인은 두 번: 보내기 전, 수정 반영 뒤. 두 번 모두 내용과 화면

## 내용

경력 원본·공고 분석과 대조:

- 사실 경계: SKILL.md 사실 경계 절 대조. 신원·시기·직무·회사·프로젝트·수치·링크 정확
- JD 대조: 지원하지 않는 요구는 공백, 진행 중·제안을 완료로 쓰지 않음, 이력서와 포트폴리오 사이 모순 없음
- 자리 글 `{}`, 양식 예시, 내부 표시, 중복 결론 없음
- 제출 문장마다 대응하는 원본 줄 또는 짝 묶음 문장 존재. 없으면 삭제
- 수정 반영 뒤: 변경 표시가 의도한 곳에만 있는지(`versions.py marks` 개수와 요청 대조)

## 기계 검사

공고 폴더에서 실행:

```bash
python3 <이 스킬 폴더>/scripts/versions.py check .
typst compile --root . 이력서/이력서.typ
typst compile --root . 포트폴리오/포트폴리오.typ
pdfinfo 이력서/이력서.pdf
pdffonts 이력서/이력서.pdf
pdftotext -layout 이력서/이력서.pdf 이력서/이력서.txt
awk '/```/{c=!c; next} !c' 이력서/이력서.typ 포트폴리오/포트폴리오.typ | grep -nE '\{|\}|·|‒|–|—|―|--'
shasum -a 256 이력서/이력서.pdf 포트폴리오/포트폴리오.pdf
```

- `versions.py check`: 양식 해시(`career.typ`가 스킬 원본과 같은지), 폴더 구조(공고 폴더 안 `이력서/`·`포트폴리오/`), 번호 파일 이름(`-NNNN` 4자리), `전략.md` 절 이름, 확정 버전의 남은 표시. 실패면 원인 수정 후 다시
- 포트폴리오도 `pdfinfo`·`pdffonts`·`pdftotext` 같은 검사. A4, 쪽 수, 한국어 글꼴, 의미 있는 텍스트 추출 확인
- 자리 글·금지 문자 검사(`awk`): 출력 0줄. 코드 블록 안은 제외. 변경 표시 함수 이름의 괄호는 검사 제외
- 컴파일 성공만으로 완료 판정 금지. 추출 텍스트는 검사 뒤 삭제

## 화면 검사

- PDF를 PNG로 렌더링(`pdftoppm -r 150 -png`) 후 쪽마다 직접 보기: 잘림, 겹침, 빈 쪽, 간격
- 한국어 줄바꿈, 목록 간격, 절 구분, 여백, 쪽 균형, 외톨이 제목, 작은 글자, 읽는 순서
- `facts` 표 행 정렬, 그림 가로 배치, 그림 글자 판독 가능, 그림과 캡션이 같은 쪽
- 수정 반영 뒤: 표시 켬(기본)과 끔(`--input changes=off`) 두 벌 모두 확인. 범례는 첫 쪽 상단
- 검토한 PDF 해시 = 전달 PDF 해시. 원본·PDF 수정 뒤 해당 문서의 컴파일·추출·글꼴·쪽·화면 검사 반복

## 기록

`전략.md` `# 확인`에 회차(보내기 전, 수정 반영 뒤), 실행한 명령, 쪽 수, 화면 결과와 개별 확인 쪽, 변경 표시 개수, PDF SHA-256, 남은 공백·근거 보강 제안, 최종 경로. 실행하지 않은 검사·ATS 통과·합격 가능성 주장 금지
