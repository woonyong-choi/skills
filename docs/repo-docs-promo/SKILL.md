# Repo Docs Promo

- 사용자 지시를 먼저 적용. 해당 주제의 사용자 지시가 없으면 작업 대상 저장소의 같은 주제 규칙 파일(예: `AGENTS.md`, `CONTRIBUTING.md`) 적용. 둘 다 없으면 이 스킬 적용. 다른 스킬과 겹치는 규칙은 머리의 연결에 적힌 스킬 중 그 규칙을 정한 스킬 적용
- 기반: repo-docs 먼저 적용. 이 스킬 범위: 저장소 밖에서 쓰는 홍보 영상의 촬영 준비물

- 녹화 자동화: 지정 도구의 시작·종료·저장 확인이 검증된 경우에만 사용. 미검증이면 사용자 수동 녹화
- README와 docs의 데모 GIF: VHS(repo-docs-figures), 이 스킬 대상 밖
- 위치: 저장소 비공개 경로 정책 우선, 기본 `.local/promo/{영상}/`. `{영상}`은 영어 소문자 kebab-case

## 폴더

아래는 macOS 실행 예. 대상 OS에 맞는 스크립트 이름·실행 명령 제공. 공통 조건은 녹화 시작 확인 뒤 재생 시작. 신호는 실행 환경에 맞게 선택하며 `go` 파일의 생성·읽기·삭제는 아래 Bash 예에만 적용

```text
.local/promo/{영상}/
  shot.md
  demo.command
  go
```

| 파일 | 내용 |
|---|---|
| `shot.md` | 촬영 순서표와 내보내기 규격 |
| `demo.command` | 실제 프로그램과 합성 데이터의 실행 또는 화면에 모형임을 표시한 재생 스크립트 |
| `go` | 재생 신호 파일. 녹화 시작 뒤 생성, 스크립트가 읽고 삭제 |

## shot.md

```text
# {영상 제목}

| 항목 | 값 |
|---|---|
| 쓰는 곳 | {랜딩 페이지, 링크드인, 블로그} |
| 보여 줄 결론 | {보는 사람이 알게 될 것 한 문장} |
| 길이 | {초}초 |
| 화면 비율 | {16:9, 1:1} |
| 데이터 | {실제 데이터, 합성 데이터, 동작 모형} |

## 장면

| 순서 | 화면 | 동작 | 길이 | 자막 |
|---|---|---|---|---|
| 1 | {보이는 화면} | {일어나는 일} | {초}초 | {자막, 또는 없음} |

## 내보내기

| 파일 | 형식 | 크기 |
|---|---|---|
| `{영상}-{비율}.mp4` | MP4, 소리 없음 | {가로}×{세로} |
```

| 자리 | 규칙 |
|---|---|
| 보여 줄 결론 | 기능 하나. README 기능 절이나 `docs/design/` 문서 제목에 있는 것만 |
| 길이 | 전달할 기능과 장면별 읽기 시간, 게시 플랫폼의 확인한 제한으로 결정 |
| 화면 비율 | 게시 플랫폼의 확인한 규격과 표시 위치 기준 |
| 장면 | 기능 흐름을 구별하는 장면, 자막은 실제 재생 속도에서 읽기 확인 |
| 데이터 | 데이터 출처·구현 여부 두 축의 판정: (repo-docs 자리표시) |
| 내보내기 크기 | 게시 플랫폼 규격을 확인하고 촬영 순서표에 크기·확인일 기록 |

## demo.command

아래는 macOS Bash용 동작 모형 예. sleep·타이핑 값은 연출 예이며 장면별 읽기 시간으로 조정. 실제 프로그램 데모는 출력 흉내 대신 실행 명령 사용

```sh
#!/bin/bash
# 동작 모형 데모. 실제 프로그램 실행이 아니다.
cd "$(dirname "$0")"
printf '\e]0;{이름}\a'
printf '\e[8;{줄};{칸}t'
clear
printf '동작 모형: 실제 실행 아님\n'
while [ ! -f go ]; do sleep 0.2; done
rm -f go
sleep 1
type_out() { local s="$1"; for ((i = 0; i < ${#s}; i++)); do printf '%s' "${s:$i:1}"; sleep 0.06; done; }
printf '$ '; type_out '{명령}'; printf '\n'
{장면별 출력}
sleep 4
```

- 합성 데이터는 repo-docs 자리표시 적용. 동작 모형은 화면에 `동작 모형: 실제 실행 아님` 표시
- 창 제목을 `{이름}`으로 변경. 창 제목과 화면에 사용자 이름, 홈 경로, 키, 실제 사용자 데이터 노출 금지
- 장면 순서와 길이: `shot.md` 장면 표 기준
- 저장 뒤 `chmod +x demo.command`로 실행 권한 부여. 권한을 바꾸는 편집 뒤에도 재확인
- 스크립트: `go` 파일이 생길 때까지 대기(녹화를 먼저 시작하기 위해)

## 촬영 순서

검증된 자동화가 없으면 사용자에게 아래 수동 순서 안내(macOS 예):

1. 사용자: Finder에서 `demo.command` 실행. 터미널 창이 열리고 빈 화면에서 정지
2. 사용자: 화면 녹화 앱에서 그 터미널 창을 녹화 대상으로 골라 녹화 시작
3. 에이전트나 사용자: `.local/promo/{영상}/go` 파일 생성. 데모 재생
4. 사용자: 재생이 끝나면 녹화 중지, 확대와 배경 편집, `shot.md` 내보내기 표대로 저장

- 자동 확대 지원은 사용 도구의 확인한 기능으로 판정, 미지원이면 장면별 수동 편집 안내

## 확인

사용자가 내보낸 파일을 받으면 아래 항목 확인:

1. 길이와 크기가 `shot.md`와 일치
2. `합성 데이터` 글자 노출(데이터가 합성 데이터일 때)
3. 사용자 이름, 경로, 알림, 다른 앱 창 미노출
4. 자막과 화면 글자에 쓰지 않는 말(repo-docs 용어 표) 없음
