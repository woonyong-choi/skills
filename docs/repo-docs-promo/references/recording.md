# demo.command

아래는 macOS Bash용 동작 모형 예. sleep·타이핑 값은 연출 예이며 장면별 읽기 시간으로 조정. 실제 프로그램 데모는 출력 흉내 대신 실행 명령 사용

```sh
#!/bin/bash
# 동작 모형 데모. 실제 프로그램 실행이 아니다.
cd "$(dirname "$0")"
printf '\e]0;{이름}\a'
printf '\e[8;{줄};{칸}t'
clear
printf '동작 모형: 실제 실행 아님\n'
while [ ! -f go ]; do sleep 0.2; done
rm -f go
sleep 1
type_out() { local s="$1"; for ((i = 0; i < ${#s}; i++)); do printf '%s' "${s:$i:1}"; sleep 0.06; done; }
printf '$ '; type_out '{명령}'; printf '\n'
{장면별 출력}
sleep 4
```

- 합성 데이터는 repo-docs 자리표시 적용. 동작 모형은 화면에 `동작 모형: 실제 실행 아님` 표시
- 창 제목을 `{이름}`으로 변경. 창 제목과 화면에 사용자 이름, 홈 경로, 키, 실제 사용자 데이터 노출 금지
- 장면 순서와 길이: `shot.md` 장면 표 기준
- 저장 뒤 `chmod +x demo.command`로 실행 권한 부여. 권한을 바꾸는 편집 뒤에도 재확인
- 스크립트: `go` 파일이 생길 때까지 대기(녹화를 먼저 시작하기 위해)

## 촬영 순서

검증된 자동화가 없으면 사용자에게 아래 수동 순서 안내(macOS 예):

1. 사용자: Finder에서 `demo.command` 실행. 터미널 창이 열리고 빈 화면에서 정지
2. 사용자: 화면 녹화 앱에서 그 터미널 창을 녹화 대상으로 골라 녹화 시작
3. 에이전트나 사용자: `.local/promo/{영상}/go` 파일 생성. 데모 재생
4. 사용자: 재생이 끝나면 녹화 중지, 확대와 배경 편집, `shot.md` 내보내기 표대로 저장

- 자동 확대 지원은 사용 도구의 확인한 기능으로 판정, 미지원이면 장면별 수동 편집 안내
