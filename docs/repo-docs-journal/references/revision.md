# 판단 변경

```text
# {바꾼 판단, 결론 문장}

| 항목 | 값 |
|---|---|
| 날짜 | {YYYY-MM-DD} |
| 이전 판단 | [{제목}]({파일}) |
| 관련 | {이슈, 공개 문서, 서사 링크} |

## 이전 판단

{한두 문장}

## 드러난 것

{무엇이 어디서 새로 보였는지 한 문단. 어디서는 구현, 실험, 버그, 검토, 조사 중 하나}

## 놓친 것

| 분류 | 원인 | 당시 신호 |
|---|---|---|
| {분류} | {왜 놓쳤는지} | {있었던 신호, 또는 없음} |

## 새 판단

{고른 것과 기준 한 문단}

## 교훈

{원칙 한 문장}. principles.md에 반영했다.
```

| 분류 | 뜻 |
|---|---|
| 사실 부족 | 확인할 수 있었는데 하지 않은 확인 |
| 잘못된 가정 | 틀린 전제 |
| 범위 착오 | 잘못 그은 대상의 경계 |
| 추론 오류 | 맞는 사실에서 잘못 끌어낸 결론 |
| 원칙 충돌 | 이미 정한 원칙과의 충돌을 못 본 경우 |
| 환경 변화 | 당시엔 맞았으나 도구, 버전, 요구가 바뀐 경우 |

- 놓친 것 표: 관측 결과를 직접 설명하는 인과 관계 순서, 확인한 원인마다 행 추가
