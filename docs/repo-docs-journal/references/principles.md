# principles.md

위치: 작업 저장소 `.local/journal/principles.md` 하나. 같은 저장소 기록의 링크 수로 반복 횟수 집계

```text
# 원칙

## {원칙 한 문장}

{어떤 판단 변경에서 나왔는지 한두 문장}

- [[{판단 변경 파일 이름}]]
- [[{판단 변경 파일 이름}]]
```

- 생성: 판단 변경의 `놓친 것` 분류와 원인이 같은 것이 두 번째 나올 때. 첫 번째는 판단 변경의 교훈 절에만
- 같은 원인 확인: `journal.py misses` 출력의 분류·원인과 대조
- 같은 교훈 재등장: 새 절 대신 링크 한 줄. 링크 수 = 되풀이 횟수
- 절 순서: 링크 수 내림차순
