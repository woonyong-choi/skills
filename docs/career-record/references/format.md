# 경력 원본 형식

경력 원본의 유일한 형식 정본. 원본 작성·추가·병합·수정·검사 때 적용. career는 이 형식을 읽기만

## 폴더

```text
<Vault>/career/
  master.md
  {소속}/
    소속.md
    {팀}/                      # 선택
      팀.md
      {프로젝트}/
        이력서.md
        포트폴리오.md
        figures/{그림}.thinkflow
  개인/{프로젝트}/...            # 개인/소속.md 구분: 개인
  {마감일}-{회사명}-{직군명}/     # 공고 폴더, career 소유
```

- 상위 위치 = 폴더 위치. 파일 안 소속·팀 이름 금지, 팀 이동은 폴더 이동만
- 폐지: master.md 프로젝트·소속 절, `cases/`, `cases/figures/`
- 그림 원본: 프로젝트 `figures/`. career가 공고 폴더 `figures/`로 복사

## master.md

```markdown
# 기본
이름: / 직무: / 이메일: / GitHub: / 전화: (선택) / 사진: (선택, 파일 경로)

# 기술
- {기술}: 실무|프로젝트|학습 (근거 프로젝트 폴더)

# 기타
- 병역·어학·자격·수상: 이름, 시기, 근거
```

- 절은 기본·기술·기타만

## 소속.md·팀.md

```markdown
---
구분: 재직
기간: 2023.03 - 현재
역할 변화: 백엔드 개발자 → 정산 담당
근거: 미확인
---
```

- 소속.md 구분: 재직|교육|개인. `개인/소속.md`는 개인
- 팀.md 속성: 기간, 역할

## 이력서.md

```markdown
---
기간: 2025.03 - 2025.09
인원: 4
역할: 백엔드
공개: 비공개
저장소:
  - https://github.com/{조직}/{저장소}
기술:
  - Kafka
  - Java
---

- 정산 배치를 주문 이벤트 처리로 전환
  - 등급: 상
  - 주체: 본인(워커 구현), 팀 4명
  - 상황: 하루 한 번 도는 배치라 정산 완료까지 6시간
  - 행동: Kafka로 주문 이벤트를 받아 정산하는 워커 구현
  - 확인: 운영 2주 관찰
  - 결과: 6시간 → 5분 (하루 12만 건 기준)
  - 상태: 완료
  - 근거: https://github.com/{조직}/{저장소}/pull/12
```

- 속성: 기간, 인원, 역할, 공개(공개|비공개), 저장소(목록), 기술(목록). 모르면 `미확인`
- 줄: 첫 줄 + 8칸 고정 순서(등급, 주체, 상황, 행동, 확인, 결과, 상태, 근거)
- 첫 줄만 저장 가능. 나머지 칸은 `미확인`, 칸 삭제 금지. 수치·역할 지어내기 금지
- 주체: `본인(맡은 부분), 팀 N명`, 혼자면 `본인`, 단순 참여면 `참여(맡은 부분)`
- 결과: 전 → 후와 측정 조건. 새 측정은 뒤에 추가, 예 `6시간 → 30분(1차) → 5분(2차)`
- 상태 변화: 그 줄 수정
- 프로젝트 폴더당 줄 10개 이하
- 줄 순서: 등급(상 → 중 → 하), 같은 등급은 최근 추가·병합 먼저

## 등급

자동 계산, 칸이 채워지면 다시 계산. 참고 값, career 선택 점수로 사용 금지

- 상: 운영 결과 수치(결과에 숫자, 확인에 운영) + 근거 링크(http) + 본인 주도(주체가 본인으로 시작)
- 중: 셋 중 하나 누락
- 하: 결과 미확인, 단순 참여(주체가 참여로 시작), 또는 둘 이상 누락

## 포트폴리오.md

```markdown
## 정산 배치를 주문 이벤트 처리로 전환

### 맡은 일
### 해결한 문제
### 설계 결정
### 구현
### 결과
### 남은 과제
```

- 묶음 하나 = 줄 하나의 짝. 줄마다 묶음 0개 또는 1개, 짝 없는 묶음 금지
- 묶음 제목 = 줄 첫 줄, 글자 그대로
- 절 6개 고정 순서. 이력서.md 사실(수치·기간·인원) 반복 금지, 이야기만
- 설계 결정: 버린 대안과 버린 이유 필수
- 남은 과제: 한계와 다음 단계
- 그림: 실제 구조·흐름만 `figures/{그림}.thinkflow`, 결론 한 문장 캡션. 코드: 저장소 경로와 커밋 기준 직접 쓴 핵심 몇 줄

## 같은 줄 판정과 병합

- 이름 유사도 판정 금지. 기존 줄 8칸과 짝 묶음, 새 PR 본문·코드를 읽고 판정
- 상황과 행동이 같으면 병합, 아니면 새 줄
- 병합: 결과(` → `)·확인·근거(`, `) 뒤에 추가, 상태 갱신, 주체·상황·행동은 미확인일 때만 채움, 짝 묶음 보강
- 줄 삭제 = 짝 묶음 삭제
