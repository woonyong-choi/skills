# 공개 결정 기록 템플릿

공개 결정 기록을 쓰거나 갱신하거나 검토할 때 이 틀과 자리 규칙을 쓴다.

````text
# {정한 것, 결론 문장}

| 항목 | 값 |
|---|---|
| 날짜 | {YYYY-MM-DD} |
| 상태 | {제안, 결정, 대체됨} |
| 대체 | {없음, 대체한 결정 링크, 대체된 결정 링크} |
| 관련 문서 | [{문서 제목}](../{파일}) |

## 배경

{무엇을 정해야 하는지, 어떤 제약과 요구가 있는지 한 문단}

## 선택지

| 선택지 | 장점 | 단점 |
|---|---|---|
| {고른 선택지} | {장점} | {단점} |
| {다른 선택지} | {장점} | {단점} |

## 결정

{고른 선택지와 가른 기준 한 문단}

## 영향

- 얻는 것: {명사구}
- 감수: {명사구}

## 다시 볼 조건

- {이 결정을 다시 검토하게 만드는 관측}
````

## 자리 규칙

| 자리 | 규칙 |
|---|---|
| 상태 | `제안`은 검토 중, `결정`은 저장소 승인 기록으로 확정, `대체됨`은 새 결정으로 바뀐 기록이다 |
| 제목 | 고른 것이 보이는 결론 문장으로 쓰고 마침표를 찍지 않는다(`플러그인과 표준 입출력으로 통신한다`) |
| 대체 | 새 기록에는 `대체한 결정: [{제목}]({파일})`, 옛 기록에는 `대체된 결정: [{제목}]({파일})`을 쓴다. 둘 다 아니면 `없음`이다 |
| 관련 문서 | 이 결정을 반영한 설계 문서다. 여럿이면 `, `로 잇는다 |
| 배경 | 현재형으로 쓰고 결정한 때 확인한 사실만 쓴다 |
| 선택지 | 검토한 대안을 모두 적고 고른 선택지를 첫 행에 둔다. 문장 열은 두지 않는다 |
| 결정 | 고른 선택지, 고른 기준, 치르는 손실을 쓴다 |
| 영향 | 얻는 것과 감수를 한 항목 이상씩 쓴다. 영어 절 이름은 `Consequences`를 그대로 쓴다 |
| 다시 볼 조건 | 관측할 수 있는 조건으로 쓴다(`플러그인 실행기가 소켓만 제공`) |
