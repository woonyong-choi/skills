# 결정 기록에서 옮기기

비공개 결정 기록(저장소 `.local/decisions/<과업>.tsv`, 형식은 **show-me-your-work** 스킬)의 줄을 공개 결정 기록으로 옮긴다. 옮기기 전에 읽는다.

## 대응

| 결정 기록 | 공개 결정 기록 |
|---|---|
| `decision` 칸 | 결정. 공개 근거로 다시 쓴 문장 |
| `why` 칸 | 배경. 잃는 것 대신 제약과 요구로 쓴다 |
| `evidence` 칸 | 공개할 수 있는 근거(이슈, PR, 공개 문서, 측정 결과)의 사실만 배경에 넣는다. 출처가 비공개(저장소 `.local/` 기록)면 넣지 않는다 |
| 같은 과업에서 비교한 다른 선택지 | 공개 근거로 확인한 대안의 장점과 단점을 다시 쓴다 |
| 판단을 뒤집은 뒤의 줄 | 다시 볼 조건 |
| `result` 칸이 `가설`인 줄, phase가 `결정 필요`나 `다음`인 줄, 놓친 것과 교훈 | 옮기지 않는다 |

## 지킬 것

- 가정, 미확인, 추정 문장은 옮기지 않는다.
- 비공개 인물 정보, 협상 비용, 내부 일정, 내부 경로, 결정 기록 링크를 넣지 않는다. 공개 근거가 있고 결정과 관련된 정보는 넣어도 된다.
- 판단이 바뀌어 공개 결정이 바뀌면 새 공개 결정 기록을 쓰고 옛 기록의 상태를 `대체됨`으로 바꾼다.
