# 작업 결정 기록에서 옮기기

비공개 작업 결정 기록(저장소 `.local/decisions/<과업>.tsv`, 열 `ts phase decision why evidence result`)의 줄 → 공개 결정 기록:

- `decision` 칸 → 결정. 공개 근거로 다시 쓴 문장
- `why` 칸 → 배경. 잃는 것 대신 제약과 요구로
- `evidence` 칸 → 공개 가능한 근거(이슈, PR, 공개 문서, 측정 결과)의 사실만 배경에. 출처가 비공개(저장소 `.local/` 기록)면 제외
- 같은 과업에서 비교한 다른 선택지 → 공개 근거로 확인한 대안의 장점과 단점을 재작성
- 판단을 뒤집은 뒤 줄 → 다시 볼 조건
- `result` 칸이 `가설`인 줄, phase가 `결정 필요`·`다음`인 줄, 놓친 것과 교훈 → 제외

- 가정·미확인·추정 문장 제외
- 비공개 인물 정보·협상 비용·내부 일정·내부 경로·작업 결정 기록 링크 금지. 공개 근거와 결정 관련성이 있는 정보는 허용
- 판단 변경이 공개 결정을 바꾸면 새 결정 기록, 옛 기록 상태는 `대체됨`
