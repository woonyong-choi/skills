# NHN Cloud 구성도 규칙

NHN Cloud 공식 자료에 따라 아이콘 종류, 서비스 경계, 하위 리소스와 경로를 표현한다. 문법과 자산 이름은 설치한 DiagramPlay와 design-tokens 카탈로그에서 확인한다.

## 적용 범위와 근거

- 클라우드 구성도를 만들거나 검수할 때 이 문서를 읽는다. 차트·데이터 관계도·상태 전이·일반 업무 흐름에 클라우드 배포 의미를 억지로 넣지 않는다.
- 기준은 사용자 제공 NHN Cloud Architecture Icons v2.2, 2026-04-08판의 슬라이드 6~8과 15~16이다. 원본 SHA-256은 `0952982bd50041cf3cf6b188bb00751e12ee32311ca9f66567bdaefc7188e219`다.
- 벡터는 [NHN 공식 저장소](https://github.com/nhn-cloud/Icons)에서 확인한다. 가이드 판과 벡터 저장소의 고정 commit은 구분한다. 두 자료를 같은 배포본이라고 추정하지 않는다.
- 예시에서 계측하지 않은 크기·선 굵기를 강제 숫자로 만들지 않는다.

## 종류와 자리

| 종류 | 쓰는 자리 | 피할 표현 |
|---|---|---|
| 서비스 아이콘 | 서비스 자체를 독립 아이콘과 이름으로 표시한다. | 업무 카드 안에 로고를 반복하지 않는다. |
| 리소스 아이콘 | 해당 서비스에 속하는 하위 리소스를 표시한다. | 다른 제품의 자원처럼 표시하지 않는다. |
| 일반 아이콘 | 서비스에 종속되지 않는 참여자·기기를 식별한다. | 이름만으로 충분한 동작의 장식으로 쓰지 않는다. |
| 박스형 아이콘 | 그룹 제목 줄에서 서비스·리전·조직·프로젝트·VPC 등을 식별한다. | 노드 카드 안에 넣거나 이름 없이 쓰지 않는다. |

- 모든 요소에 아이콘을 붙이지 않는다. 주문 접수·검증·재고 예약처럼 이름으로 충분하면 기본 도형과 글만 쓴다.
- 구성도 아이콘을 다른 일반 세트나 임시 제작 SVG와 섞지 않는다. 없는 로고를 비슷하게 그려 대체하지 않는다.
- 원본 도형과 색을 보존한다. 표시 크기와 정렬은 공통 토큰과 렌더러가 정한다.
- 설치한 카탈로그에 이름과 종류가 있는지 먼저 확인한다. 없으면 공통 정본의 원본·버전·해시·권리 고지를 갱신한다. 소비자에 SVG를 복제하거나 이름을 지어내지 않는다.
- 조작 버튼은 기존 design-tokens controls와 공통 컴포넌트를 그대로 사용한다. 복사·다운로드·전체화면 버튼을 다시 만들지 않는다.

## 그룹과 중첩

- 박스형 아이콘과 명시적 이름을 그룹 제목 줄에 둔다. 직각 경계와 제목을 한 덩어리로 사용한다. 선과 부딪히면 제목 덩어리를 옮길 수 있다.
- 중첩은 실제 포함 관계를 나타낸다. 리전·조직·프로젝트·VPC·서비스와 하위 리소스를 자료에 맞게 묶는다. 처리 순서를 꾸미려고 포함 관계를 만들지 않는다.
- 슬라이드 8·15의 Availability Zone과 일반 그룹처럼 이름과 경계로 표시된 영역도 구분한다. 맞는 박스형 자산이 없다는 이유로 다른 서비스 아이콘을 대신 쓰지 않는다.
- 배포 정보가 없으면 구성 모형이라고 명시한다. 예시를 실제 운영 구성이나 성능·복구 보장으로 설명하지 않는다.

## 경로와 상태

- 기본적으로 주 경로는 실선, 보조 경로는 점선으로 구분한다. 성공은 공통 초록 역할, 실패는 빨강 역할로 표현하고 상태 글을 함께 둔다.
- 비동기라는 이유만으로 모든 주 흐름을 보조 경로로 만들지 않는다. 같은 선을 호출과 응답에 겸용하지 않는다.
- 슬라이드 16의 예시는 방향·굵기·실선·점선을 함께 보여 준다. 점선을 항상 실패와 같은 뜻으로 간주하지 않는다.
- 선 모양과 글만으로도 관계를 읽을 수 있게 한다. 관계를 설명하지 않는 장식용 이동을 추가하지 않는다.

## 배치와 검수

- 읽는 순서와 짧은 연결을 우선한다. 고정 본문 폭에 맞추려고 사슬을 접어 긴 우회를 만들지 않는다.
- 일반 보기에서는 자연 배치를 가용 가로 폭에 맞춰 비례 축소한다. 가로 스크롤 없이 전체 폭을 표시하고 세로 길이는 허용한다. 전체화면 확대·맞춤도 확인한다.
- 복잡한 설계의 요소와 연결을 수량 목표 때문에 지우지 않는다. 전체 구조를 보존하고 상세 보기가 필요하면 같은 항목을 이어서 볼 수 있게 나눈다.
- 라이트와 다크에서 아이콘·이름·경계·선을 실제로 확인한다. 같은 바이트라는 사실을 두 배경의 가독성 합격으로 대신하지 않는다.
- 박스형 아이콘의 노드 사용, 서비스·리소스의 장식 카드 사용, 이름 없는 그룹과 잘못된 중첩을 검사한다.
- 교차 마스킹, 선 끝과 도형 경계, 긴 우회, 잘림, 가로 넘침을 확인한다. 정지 SVG와 재생 장면이 같은 요소·경로를 전달해야 한다.

## 사용 목적과 권리

- [공식 README](https://github.com/nhn-cloud/Icons#readme)는 NHN Cloud 아키텍처 다이어그램 작성 용도를 안내한다. 일반 오픈소스 라이선스는 명시되어 있지 않다.
- 비상업용이라는 사실을 포괄적 상업 이용이나 원본 재배포 허용으로 바꾸지 않는다. 출처와 고지를 보존하고 NHN 자산을 도구의 MIT 라이선스로 재라이선스하지 않는다.
