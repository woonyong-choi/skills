# 그림 작성

Torso 그림 원본을 쓰거나 바꿀 때 보여 줄 것에 맞는 정본을 읽고 배치를 정한다.

## 정본 고르기

보여 줄 것에 맞는 정본을 [reference](https://github.com/woonyong-choi/torso/blob/main/docs/reference)에서 읽는다.

| 보여 줄 것 | 정본 |
|---|---|
| 맥락, 구성 요소와 요청 흐름 | `flow.md`, `architecture.md` |
| 메시지 순서 | `sequence.md` |
| 상태와 전이 | `state.md` |
| 테이블과 외래 키 | `data.md` |
| 비트 필드, 배열, 스택, 행렬 | `grid.md` |
| 측정한 시간 구간 | `timing.md` |
| 조건별 값과 신뢰구간, 비교, 분포, 관계, 변화, 교차표, 차이 | `charts.md`. 차이 값은 차이 차트로, 조건별 원래 값은 막대나 덤벨로 그린다 |

## 배치

방향, 접기, 그림 나누기는 [그림 품질](torso-quality.md)의 가로형 원칙과 4절을 따른다. 그림은 SVG와 HTML 모두 칸 폭을 채우고 가로로 스크롤하지 않으며, 좁은 화면 HTML에서는 Torso가 미리 만든 좁은 배치로 바꾼다. 글이 읽히는지는 실제 폭에서 확인한다.

## 내용

- 라벨, 상태, 테이블, 열은 문서 표와 같은 이름과 순서로 쓴다. 연결은 문서에 근거가 있는 관계만 긋는다.
- 맥락 그림에는 외부 요소 표의 요소와 시스템을 그린다. 구성 요소 그림에는 구성 요소 표의 행마다 카드 하나를 그리고, 카드가 그림 한도를 넘으면 [그림 품질](torso-quality.md) 1절 5번대로 합치거나 나눈다.
- `title`은 그림 주제다. `scene`은 순서나 변화가 이해를 도울 때만 쓴다.
- 구조, 상태, 데이터 그림의 정지 SVG는 장면과 상관없이 선언한 모든 선을 그린다. 순서 그림은 [그림 품질](torso-quality.md#품질이-무너지는-원인)의 장면 규칙을 따른다.
