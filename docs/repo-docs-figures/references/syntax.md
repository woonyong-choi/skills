# 그림 작성

Torso 그림 원본을 쓰거나 바꿀 때 보여 줄 것에 맞는 정본을 읽고 배치를 정한다.

## 정본 고르기

보여 줄 것에 맞는 정본을 [reference](https://github.com/woonyong-choi/torso/blob/main/docs/reference)에서 읽는다.

| 보여 줄 것 | 정본 |
|---|---|
| 맥락, 구성 요소와 요청 흐름 | `flow.md`, `architecture.md` |
| 메시지 순서 | `sequence.md` |
| 상태와 전이 | `state.md` |
| 테이블과 외래 키 | `data.md` |
| 비트 필드, 배열, 스택, 행렬 | `grid.md` |
| 조건별 값과 신뢰구간, 비교, 분포, 관계, 변화, 교차표, 차이 | `charts.md`. 차이 값은 차이 차트로, 조건별 원래 값은 막대나 덤벨로 그린다 |

## 배치

- 방향을 적지 않는다. 기본 배치가 가로이고 본문 단을 넘으면 Torso가 돌린다. `view graph`는 보기를 둘 이상 둘 때만 이름과 함께 쓰고(`view graph "구조"`), `down`은 위아래에 뜻이 있을 때만 적는다.
- 세로로 바꿀지는 카드 수가 아니라 배치 폭으로 정한다. 카드 글, 선 라벨, 분기 층을 포함한 가로 배치가 배치 목표 폭(본문 단 680px, 머리 `width wide`면 1440px)을 넘으면 Torso가 세로로 바꾸거나 접는다. 렌더한 SVG가 세로 한 줄이나 계단이면 [그림 품질](torso-quality.md)의 배치 규칙으로 고친다.
- 좁은 화면(모바일 분기점 미만) HTML에서는 Torso가 미리 만든 좁은 배치(대개 세로)로 바꾸고, 남는 폭은 그림 안에서 가로로 스크롤한다. 잘리는지는 실제 폭에서 확인한다.

## 내용

- 라벨, 상태, 테이블, 열은 문서 표와 같은 이름과 순서로 쓴다. 연결은 문서에 근거가 있는 관계만 긋는다.
- 맥락 그림에는 외부 요소 표의 요소와 시스템을 그린다. 구성 요소 그림에는 구성 요소 표의 행마다 카드 하나를 그린다.
- `title`은 그림 주제다. `scene`은 순서나 변화가 이해를 도울 때만 쓴다.
- 구조, 상태, 데이터 그림의 정지 SVG는 장면과 상관없이 선언한 모든 선을 그린다. 순서 그림의 정지 SVG는 고른 장면(기본은 첫 장면)의 메시지만 그리므로 한 장에 보여야 할 메시지는 첫 장면에 둔다([그림 품질](torso-quality.md#품질이-무너지는-원인)).
