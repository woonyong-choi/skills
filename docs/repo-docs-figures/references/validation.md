# 검사

DiagramPlay 그림을 변환하거나 검사할 때, 변환 도구를 바꿀 때 다음 순서로 확인한다.

## 단계

1. `diagramplay check --strict`를 돌려 출력이 없고 종료 코드가 0인지 확인한다. 소스 설치에서는 [설치와 실행](execution.md)의 `node` 접두사를 붙인다.
2. 실험 차트는 `data` 출처와 신뢰구간 계열이 실제 결과 파일을 읽는지, 부제의 표본 수가 그 파일의 n과 같은지 확인한다. 문서 안 블록은 `md --check --strict`로 확인한다.
3. 원본 수를 SVG 수, 문서 링크 수와 대조한다. 이름이 같은 다른 원본을 한 `--out`에 쓰지 않는다.
4. 같은 원본, 입력 JSON, 도구 커밋으로 두 번 변환해 SVG 바이트가 같은지 확인한다. VHS는 뺀다.
5. 실제 문서 삽입 환경에서 라이트와 다크의 글자, 겹침, 잘림, 빈 영역과 움직임을 확인한다. 시간차 두 장면과 정지 출력을 대조하고, 정지 출력에 움직임이 없는지 확인한다.
6. 모든 그림의 대체 글과 자리표시를 확인한다. README 그림 배치와 개수는 repo-docs-readme를 따른다.
7. 변환 도구를 바꿨으면 [도구와 파일 절](../SKILL.md#도구와-파일)의 도구 교체 조건을 실제 기존 문서 호출과 실험 데이터 입력으로 확인한다. 오류 원본에서 check와 render가 실패하는지 확인한다.

## 지킬 것

- `--strict`는 경고도 실패로 본다. 출력이 남으면 진단을 해결하고 다시 검사한다.
- 기계 검사 통과로 실제 문서의 재생과 가독성 확인을 대신하지 않는다.
