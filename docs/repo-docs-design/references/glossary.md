# glossary.md

`docs/glossary.md`를 쓰거나 갱신하거나 검토할 때 이 틀을 쓴다.

````text
# 용어

이 프로젝트에서만 쓰는 말이다. 업계에서 널리 쓰는 말은 넣지 않는다.

| 용어 | 뜻 | 원어와 코드 이름 |
|---|---|---|
| {고유 용어} | {용어가 가리키는 대상의 정의} | `{원어 또는 코드 이름}` |
````

- 행은 가나다순으로 놓고, 영문은 한글 뒤에 알파벳순으로 놓는다.
- 문장으로 쓰는 열은 `뜻`이다. 무엇인지만 쓰고 동작은 쓰지 않는다.
- `원어와 코드 이름`이 없으면 `없음`으로 쓰고, 여럿이면 `, `로 잇는다.
- 같은 이름이 다른 대상을 가리키면 `뜻` 칸 끝에 가르는 조건을 더한다.
