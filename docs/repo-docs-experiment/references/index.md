# 실험 목록

`docs/experiments/README.md`를 쓰거나 갱신하거나 검토할 때 이 틀을 쓴다.

```text
# 실험

| 실험 | 확인할 것 | 관련 설계 | 결론 |
|---|---|---|---|
| [{실험}]({실험}/report.md) | {확인할 것} | [{문서 제목}](../{파일}) | {결론 한 줄} |
```

- 행은 수집 전 계획 커밋 순서로 놓는다.
- 링크 글자는 폴더 이름 그대로 쓰고 인라인 코드로 감싸지 않는다.
- 보고서가 나오기 전에는 `{실험}/design.md`에 링크하고 결론 칸에 `측정 전`을 쓴다.
- 결론은 `{가설} {채택, 기각, 보류}: {수치}`로 쓴다(`H1 채택: 오분류율 3.1% [2.0, 4.7]`).
