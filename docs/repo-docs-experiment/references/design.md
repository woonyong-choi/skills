자리 → 규칙:

- 확인할 것 → 한글 명사구. 폴더 이름과 같은 뜻
- 가설 → `H1`, `H2` 순. `예측`: 문장 열, 틀렸다고 판정할 수 있는 한 문장: `오분류율은 5% 이하다.`
- 지표 종류 → 조건 값: 실험자가 바꾸는 것, 측정 값: 관측하는 것, 계산 값: 계산하는 것
- 크기 근거 → 정밀도면 목표 신뢰구간 반폭, 검정력이면 효과 크기와 α, β, 수집 한도면 허용 표본 수와 제한 이유
- 채택 기준 → 자료 유형·대응 여부·가정·방법 출처를 명시하고 신뢰수준과 판정 경계를 수집 전 고정. 점추정만으로 불확실성 대체 금지
- 조건과 실행 순서 → 조건 하나면 조건 칸 `단일 조건`. 실행 순서 칸: 입력 순서 결정 방법과 시드, 순서 미정이면 `해당 없음`
- 실험 환경 → 이 표만으로 다른 사람이 같은 환경 재현 가능. `최신`, `기본값` 금지, 실제 값만. 모르는 값은 `확인 못 함`과 이유
- 조건별 값 → 조건마다 다르게 준 설정 전부. 조건 하나면 절 생략
- 위험 요소 → 다른 원인이 결과를 만들 가능성, 지표가 재려는 것을 재는지, 다른 환경에도 맞는지 각각 한 행 이상. 문장 열: `위험 요소`, `대응`
- 추가 분석 → 없으면 절 생략
- 모든 칸 → 채우기 필수, 미적용은 `해당 없음`. 미정 칸이 있으면 저장 금지, 정할 항목 보고
