```text
# {확인할 것}: 실험 설계

| 항목 | 값 |
|---|---|
| 이슈 | [#{번호}]({URL}) |
| 관련 설계 | [{문서 제목}](../../{파일}) |
| 사전 데이터 | {없음, 또는 미리 본 데이터와 이유} |

## 질문

{설계에서 무엇을 정하려고 무엇을 측정하는지 두 문장}

## 가설

| 가설 | 예측 | 적용 범위 |
|---|---|---|
| H1 | {방향과 크기가 있는 예측} | {입력, 플랫폼, 버전 범위} |

## 설계

| 항목 | 값 |
|---|---|
| 조건 | {비교 조건. 기준 조건 포함} |
| 배정 | {무작위 순서와 시드} |
| 눈가림 | {누가 무엇을 보지 않는지, 또는 해당 없음} |
| 환경 | {운영체제, 도구, 모델과 버전} |

## 변수

| 변수 | 종류 | 정의 | 단위 |
|---|---|---|---|
| `{이름}` | {조작, 측정, 파생} | {정의나 계산식} | {단위} |

## 표본

| 항목 | 값 |
|---|---|
| 출처 | {입력을 얻는 곳} |
| 크기 | 조건마다 {n} |
| 크기 근거 | {정밀도, 검정력, 예산, 전수} 중 하나와 계산 |
| 중단 규칙 | {언제 수집을 멈추는지} |
| 반복과 예열 | {반복 수, 버리는 예열 수} |

## 분석

| 가설 | 지표 | 방법 | 채택 기준 |
|---|---|---|---|

## 타당성 위협

| 종류 | 위협 | 대응 |
|---|---|---|
| {내적, 구성, 외적} | {위협} | {대응} |
```

| 자리 | 규칙 |
|---|---|
| 확인할 것 | 한글 명사구. 폴더 이름과 같은 뜻 |
| 가설 | `H1`, `H2` 순. `예측`: 문장 열, 틀렸다고 판정할 수 있는 한 문장: `오분류율은 5% 이하다.` |
| 변수 종류 | 조작: 실험자가 바꾸는 것, 측정: 관측하는 것, 파생: 계산하는 것 |
| 크기 근거 | 정밀도면 목표 신뢰구간 반폭, 검정력이면 효과 크기와 α, β, 예산이면 비용 한도 |
| 채택 기준 | 자료 유형·대응 여부·가정·방법 출처를 명시하고 신뢰수준과 판정 경계를 수집 전 고정. 점추정만으로 불확실성 대체 금지 |
| 조건과 배정 | 조건 하나면 조건 칸 `단일 조건`. 배정 칸: 입력 순서 결정 방법과 시드, 순서 미정이면 `해당 없음` |
| 모든 칸 | 채우기 필수, 미적용은 `해당 없음`. 미정 칸이 있으면 저장 금지, 정할 항목 보고 |
| 타당성 위협 | 문장 열: `위협`, `대응`. 종류마다 한 행 이상 |
| 탐색 분석 | 없으면 절 생략 |
