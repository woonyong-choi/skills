자리 → 규칙:

- 계획과 다른 점 → 없으면 표 대신 문장 `계획과 다른 점은 없다.` `env.json` 값이 계획의 실험 환경과 다르면 여기에 행 추가
- 데이터 처리 → 제외는 이유마다 한 행, 실패한 실행도 한 행
- 가설 검증 → 계획의 가설 표와 같은 순서
- 그림 → 서로 다른 주장을 보여 주는 결과 그림만. 대체 글: 판정이 보이는 결론 한 문장, `프롬프트 A의 오분류율 신뢰구간 상한이 기준 5%보다 낮다`
- 추가 분석 → 판정에 사용 금지, 없으면 절 생략
- 해석 → 결과·설계 영향 포함
- 위험 요소 점검 → 계획의 위험 요소 표 행 전부. 문장 열: `위험 요소`, `이 실험에서`
- 결론 반영한 문서 → 미반영이면 `없음`, 이유는 해석 절에
