# Code Refactoring

- 우선순위: 해당 주제의 사용자 지시 → 저장소 규칙 → 이 스킬. 중복 규칙은 머리에 연결한 정본 스킬 적용
- 기반: code-style 먼저 적용. 이 스킬 범위: 문제 신호별 해결 기법 선택, 『리팩터링 2판』 기법 목록. 그 밖에서 code-style과 다르면 code-style 우선

## 절차

1. 책임·의존·미사용 경로 확인, 문제 신호 하나 선택. 수치 기준 초과 여부와 별도 판단
2. 해결 기법 하나를 작은 단계로 적용. 단계마다 빌드·테스트. 동일 값을 계산하는 생산 코드와 표시 코드는 계산 정본 하나 공유
3. 책임·의존 변화로 개선 확인. 파일 수 증가 자체를 구조 개선으로 계산 금지

## 문제 신호 → 해결 기법

왼쪽 신호가 보이면 오른쪽 기법 중 선택해 적용. 기법 설명: 기법 목록 절

| 문제 신호 | 해결 기법 |
|---|---|
| 이름만 보고 역할을 알 수 없음 | 함수 시그니처 변경, 변수 이름 변경, 필드 이름 변경 |
| 여러 곳의 같은 코드 | 함수 추출, 코드 순서 옮기기, 메서드 올리기 |
| 변경 이유가 둘 이상이거나 code-style 함수 길이 기준을 넘는 함수 | 함수 추출, 임시 변수를 함수로, 매개변수 묶음 타입 도입, 객체 통째로 전달, 함수를 명령 객체로, 조건문을 함수로 분리, 분기를 다형성으로, 반복문 분리 |
| 서로 다른 책임의 입력이 섞이거나 code-style 매개변수 수 기준 초과 | 매개변수를 내부 조회로, 객체 통째로 전달, 매개변수 묶음 타입 도입, bool 플래그 인자 제거, 관련 함수를 타입으로 묶기 |
| 어디서나 바꿀 수 있는 전역 변수 | 변수 캡슐화 |
| 여러 곳에 흩어진 값 변경 코드 | 변수 캡슐화, 변수 분리, 코드 순서 옮기기, 함수 추출, 조회와 변경 분리, setter 제거, 계산 가능한 필드를 함수로, 관련 함수를 타입으로 묶기, 파생값 계산을 변환 함수로 묶기, 참조를 값으로 |
| 서로 다른 이유로 자주 바뀌는 모듈 | 처리 단계 분리, 함수 이동, 함수 추출, 타입 분리 |
| 기능 하나 변경에 여러 모듈의 작은 수정 필요 | 함수 이동, 필드 이동, 관련 함수를 타입으로 묶기, 파생값 계산을 변환 함수로 묶기, 처리 단계 분리, 함수 인라인, 타입 합치기 |
| 자기 모듈보다 다른 모듈 데이터를 더 많이 쓰는 함수 | 함수 이동, 함수 추출 |
| 같은 값 묶음이 여러 곳에 함께 등장 | 타입 분리, 매개변수 묶음 타입 도입, 객체 통째로 전달 |
| 기본 타입(int, string)으로 다루는 금액·범위·상태 코드 | 기본 타입을 값 타입으로, 타입 코드를 하위 타입으로, 분기를 다형성으로, 타입 분리, 매개변수 묶음 타입 도입 |
| 같은 switch·match 분기가 여러 곳에 반복 | 분기를 다형성으로 |
| 의도를 가리는 반복문 | 반복문을 map·filter로 |
| 하는 일에 비해 과한 구조 | 함수 인라인, 타입 합치기, 계층 합치기 |
| 나중을 대비해 만든 안 쓰는 코드 | 계층 합치기, 함수 인라인, 타입 합치기, 함수 시그니처 변경, 안 쓰는 코드 삭제 |
| 특정 상황에서만 값이 채워지는 필드 | 타입 분리, 함수 이동, 특수 케이스 객체 |
| `a.b().c().d()` 같은 긴 호출 체인 | 위임 숨기기, 함수 추출, 함수 이동 |
| 대부분 다른 객체에 넘기기만 하는 래퍼 | 위임 래퍼 제거, 함수 인라인, 부모 클래스 상속을 위임으로, 하위 클래스 상속을 위임으로 |
| 서로의 내부 데이터를 직접 주고받는 모듈 | 함수 이동, 필드 이동, 위임 숨기기, 하위 클래스 상속을 위임으로, 부모 클래스 상속을 위임으로 |
| 독립된 변경 이유가 둘 이상인 클래스·struct | 타입 분리, 부모 타입 추출, 타입 코드를 하위 타입으로 |
| 같은 일을 하는데 인터페이스가 다른 타입들 | 함수 시그니처 변경, 함수 이동, 부모 타입 추출 |
| 데이터만 있고 관련 로직은 밖에 있는 타입 | 레코드 캡슐화, setter 제거, 함수 이동, 함수 추출, 처리 단계 분리 |
| 상속받은 기능 대부분 미사용 | 메서드 내리기, 필드 내리기, 하위 클래스 상속을 위임으로, 부모 클래스 상속을 위임으로 |
| 코드가 하는 일을 설명하는 주석 | 함수 추출, 함수 시그니처 변경, assert 추가 |
