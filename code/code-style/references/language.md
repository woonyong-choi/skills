# 언어별 스킬

언어별 스킬이 무엇을 정하고 공통 규칙과 어떻게 함께 쓰이는지 정한다.

- 작업 언어의 스킬이 있으면 함께 적용한다. 없으면 그 언어의 공식 스타일 가이드를 따른다.
- 언어별 스킬 이름은 `code-style-<언어>`로 짓는다. 절 이름은 이 스킬과 같게 두고 공통 규칙을 다시 쓰지 않는다.
- 언어별 스킬은 아래 항목만 정한다. 목록 밖에서 공통 규칙과 부딪히면 공통 규칙을 따른다. 부딪히지 않는 언어 고유 규칙은 더해 적용한다.

## 언어별 스킬이 정하는 항목

- 대소문자 표기와 포맷
- 언어 관례가 있는 이름 형식(접근자, 생성, 변환, 반복자)
- 언어마다 문법이 다른 것(오류 값, 예외, 단언, 공개 범위 키워드, 접근 메서드나 프로퍼티 같은 필드 접근 방식, 문서 주석 형식, import와 모듈 선언)
- 오류와 로그 메시지의 대소문자와 마침표
- 선언 순서 중 언어 문법이나 공식 규칙 때문에 달라지는 부분(불변과 가변 구분이 없는 필드, Kotlin companion object처럼 공식 규칙이 위치를 정한 항목, import 정렬 도구의 순서)
- 테스트 위치
- 라이브러리 기본값(로그, 오류 타입)
- 린터 설정과 검사 명령
- 선택자, 값과 단위, 반응형과 접근성(CSS만)

## 있는 스킬

- Rust, Kotlin(JVM 서버와 CLI), Python, TypeScript(JavaScript 포함), CSS가 있다. CSS에는 함수, 오류, 로그 항목이 해당하지 않는다.
