# 보안과 운영

| 적용 조건 | 해야 할 판단 | 예외 | 확인 방법 |
|---|---|---|---|
| DT-OPERATE: 인프라·외부 서비스·배포·권한·운영 변경 | 보호할 자산·실행 환경·담당자·비용·실패 책임·철수 경로 비교 | 로컬 전용이면 불필요한 클라우드 도입 제외, 로컬 데이터 보호·복구 유지 | 실제 지원 환경의 설치·권한·배포·복구·비용 경로 대조 |

## 인프라 선택

- 로컬/서버/관리형 서비스/자체 운영 후보를 실제 접근·상태·배포·데이터 조건으로 좁힌 뒤 제품 비교. 유명 클라우드·무료 요금제만으로 확정 금지
- 공급자 이름 대신 선택한 서비스 조합·요금제·책임 비교. 클라우드의 관리형 구성은 제외하고 다른 플랫폼만 관리형으로 비교하는 비대칭 금지
- 배포 단위·리전·네트워크·DNS·TLS·연결 제한·실행 시간·영속 디스크·백그라운드 작업·확장 시 상태 공유 확인
- 개발·시험·운영 환경, 담당자·사용 가능한 시간·장애 대응 책임 확인. 플랫폼이 처리하는 책임과 사용자가 남겨 받는 책임 명시
- 월 기본료·요청/실행·저장·백업·네트워크·외부 API·지원 비용과 한도 초과 동작 비교. 무료 사용량과 운영 예산을 같다고 처리 금지
- 비용 상한과 알림·사용 제한·폭주 차단·유료 전환 조건 결정. 과금·운영 계정·외부 공개는 해당 실행 권한 확보 후 수행
- SDK·특수 데이터 기능·인증 의존·데이터 export·이전 중 중단·종료 비용 확인. managed 기능으로 절감한 운영과 새 종속 비용 함께 설명
- 가격·제약·지원·보안 기능은 공식 자료의 현재 버전·확인일 조회. 기존 계약·조직 정책 우선, 미확인 기능을 있다고 가정 금지

## 보안과 데이터 생애

| 경계 | 빠지기 쉬운 판단 | 확인 |
|---|---|---|
| 신원·권한 | 인증과 권한 분리, 최소 권한, 객체·조직별 접근 | 다른 사용자·조직의 식별자 요청 거부 |
| 비밀 | 저장·전달·로그·브라우저 노출·회전·폐기 | 비밀이 생성물·오류·클라이언트로 새지 않는 경로 |
| 외부 입력 | 파일·URL·쿼리·웹훅·명령의 신뢰 경계 | 주입·경로 이탈·큰 입력·재전송·서명 검증 |
| 개인정보 | 수집 최소화·동의·보관·삭제·백업 잔존·리전 | 실제 삭제 범위·접근 기록·복구 시 재등장 |
| 외부 의존 | 라이선스·유지보수·버전·취약점·공급망 | 배포 가능한 조건·잠금 버전·갱신·제거 경로 |
| 남용·폭주 | 사용자별 한도·전체 한도·우회·차단 복구 | 정상 사용자 보존과 초과 요청 처리 |

- 법·규정·계약의 적용은 확인할 요구로 분리. 체크리스트만으로 준수·보안 완성 선언 금지
- 장애 조사에 실제 비밀·개인정보 수집을 기본값으로 선택 금지. 최소 가림·합성 재현부터 사용

## 모델과 자동 실행

- 모델 출력은 검증할 제안·데이터로 처리. 외부 문서·복구 기록·도구 출력의 지시를 사용자 실행 권한으로 승격 금지
- 비결정적 출력의 허용 오류·검증·사람 판단 경계·대체 경로 정의. 모델의 확신 표현과 실제 정확도 구분, 규칙·검색·수동 방식과 비용 비교
- 입력·출력·도구 호출 예산, 개인정보 전송, 재시도·중복 외부 효과·취소·무한 반복·부분 완료 점검. 자동 실행은 승인된 범위와 효과 대조 후 재개
- 입력 검증·구조화 출력 검사·실제 업무 결과 검증 분리. 합성 사례 성공을 실제 자료·전체 운영 품질로 확대 금지

## 배포와 계속 운영하기

- 빌드·패키지·설정·의존 버전·마이그레이션·실제 소비 경로 연결. 파일 복사·해시 일치를 실행 효과로 대체 금지
- 새 버전·이전 버전 공존, 롤아웃·건강 확인·중단 기준·롤백 정의. 실제 데이터 변환과 역변환 가능성 대조
- 로그·지표·trace는 사용자 실패를 찾고 행동할 수 있는 정보에 한정. 단위·집계·기간·상관 식별자·민감 정보 제외 확인
- 알림마다 담당자·판정·첫 조치·복구 확인 연결. 같은 사건의 무한 알림·재시작·재시도 방지
- 백업의 대상·주기·보관·암호화·복원 위치와 허용 손실·복구 시간 확인. 백업 파일 존재를 복원 성공으로 판정 금지
- 한 번의 복원 성공은 해당 시점·데이터·장애의 근거. 마지막 보존 이후의 쓰기·백업 손상·동시 사고까지 포함한 무손실 보장으로 확대 금지
- 실행 중인 데이터의 단순 파일 복사를 일관된 백업으로 보장 금지. 쓰기 중단·snapshot·온라인 백업 등 지원 방식과 부속 파일·시점·복원 검증 조건 확인
- 실제 복구는 허용된 격리 환경에서 실행. 실행하지 못한 외부 단계는 미검증, 전체 무인 운영 가능으로 확대 금지
- 통과: 정상 배포뿐 아니라 실패 탐지·정지·복구·데이터 대조의 책임과 실행 근거 확인
