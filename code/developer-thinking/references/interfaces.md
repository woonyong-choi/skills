# G2 화면 · API

| ID·조건 | 구현 전 확정 | 필수 검사 |
|---|---|---|
| I1 사용자 행동 | 첫/반복 사용·수정·취소·복구의 입력→요청·권한→응답→상태→완료 신호 | 실제 과업 완료와 실패 후 복구 |
| I2 상태 | 정상·로딩·빈 결과·오류·부분 결과·권한 없음·저장 중·성공 후 | 빈 결과≠읽기 실패. 완료 표시≠영속화 성공 |
| I3 클라이언트 데이터 | 서버 정본/편집 값/일시 UI 상태의 단일 소유자, 낙관적 실패·취소·충돌 정책 | 연속 입력·중복 제출·응답 역전·화면 이탈 |
| I4 API | 타입·단위·입력 검증·객체 권한·오류·재시도·페이지/정렬·버전·호환 소비자 | 형식과 업무 정답 별도 대조. HTTP 성공만으로 완전한 결과 판정 금지 |
| I5 지원 환경 | 단절·재연결·오프라인 수정·기기 저장/권한/백그라운드 수명 | 개발 환경 성공을 다른 환경으로 승계 금지 |
| I6 구성 요소 | 기존 컴포넌트·토큰·역할별 변형 우선, 새 역할과 기존 상태 구분 | 동일 역할의 표현·상태·모션 일치 |
| I7 시각·접근성 | 작은 화면·확대·키보드·초점·대비·테마·긴 내용 중 지원 조건 | 실제 크기·상태 렌더 대조. 빌드·토큰 일치만으로 통과 금지 |
| I8 모션 | 목적·속성·시간·곡선·중단·연속 입력·로딩·모션 감소 | 상태·초점·사용자 행동 차단 없음 |
| I9 기존 UI 개선 | 의미·실루엣·정보 위계·색 역할 보존 | 같은 크기·상태의 대표 전후 대조 후 범위 확대 |

- 파일·URL·쿼리·명령 등 신뢰 경계의 외부 입력 처리 전 [보안·운영](operations.md) 필수 조회
- 잘림·누락·전송 중단·연결 재개 상태 대조. 시안 범위 요청은 시안으로 종료, 실제 제품 완료 주장 금지
- 용어·단위·오류 위치·복구 행동 확인. 내부 구현을 알아야만 사용 가능한 제품 흐름 수정
