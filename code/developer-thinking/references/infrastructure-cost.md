# 구매 · 구축 · 인프라 비용

적용: SaaS 도입·구매/구축·호스팅·요금제 선택과 변경. 먼저 현재 [스펙](requirements.md) 확인. 공급자 이름 대신 같은 사용자 과업을 완료하는 구성으로 비교한다.

| 후보 | 먼저 확인할 적합 조건 | 비교할 대가 |
|---|---|---|
| 기존 SaaS 설정 | 필요한 업무·권한·데이터 입출력이 기본 기능으로 충족 | 좌석/사용량 요금·변경 가능 범위·반출·종속 |
| SaaS + API 연동 | 필요한 차이를 확장·연동으로 충족 | API 한도·동기화·인증·중복/실패 처리·양쪽 비용 |
| 관리형 서비스 조합 | 고유 화면·업무 규칙을 구현하고 실행/DB/인증 등을 위탁 | 남는 개발·보안·운영 책임, 서비스별 한도·과금 |
| 직접 구축·운영 | 계약·통제·운영·비용상의 이점과 운영 가능 근거 존재 | 개발·배포·패치·관측·복구·인력·이전 책임 |

- 위 후보는 단계별 강제 통과 목록이 아닌 비교 후보. 현재 구성 재사용·혼합도 허용. 모두 미충족이면 제약 조정안을 설명하고 선택 전 구현 보류
- 클라우드 공급자 하나에도 관리형·직접 운영 구성이 공존. 공급자 이름과 SaaS라는 범주를 동등한 후보로 점수화 금지

## 후보 비교

| 확정할 것 | 후보마다 확인 | 탈락·보류 기준 |
|---|---|---|
| 필요한 기능 | 같은 사용자 과업·권한·변경 자유도·연동·내보내기. 필요한 실행/DB/파일/인증/큐/관측의 포함 범위 | 미제공 기능·용량·성능을 가격만으로 충족 판정 금지. 미요청 기능을 필요로 만들어 후보 선정 금지 |
| 실행 계약 | 지원 언어·배경 작업·시간 제한·연결 수·영속성·리전·네트워크 | 필수 계약 위반은 근거와 제외. 미확인은 확인 전 확정 금지 |
| 운영 책임 | 설치·패치·배포·백업·복원·모니터링·장애 대응의 담당자·작업 시간 | 관리형도 남는 책임 명시. 운영자 미정이면 직접 운영을 무료로 간주 금지 |
| 보존·철수 | 내보내기 형식·이전 경로·인증/파일/DB 의존·중단 시간·나가는 트래픽 | 코드 교체만으로 데이터·권한 이전 완료 판정 금지 |
| 비용·한도 | 아래 같은 사용량·기간·통화로 산정한 현금 비용, 초과·차단 동작 | 무료 구간만 비교하거나 비용 불명 항목을 0으로 처리 금지 |

- 스펙에 맞는 실제 후보만 비교. 후보 수 채우기 금지. 필수 조건별 근거·충족/위반/미확인 대조, 미확인 조건이 남은 후보에 전체 통과 표시 금지
- 로컬/원격과 관리형/직접 운영은 별도 축. 특정 공급자에 관리형 서비스가 없다고 가정하는 비대칭 비교 금지
- 현재 버전·리전·요금제의 공식 가격·한도·과금 단위·확인일 기록. 조회 불가면 후보와 확인 방법만 제시, 가격·가능 여부 확정 금지

## 비용 계산

1. 입력: 정상 사용량·근거 있는 최대 사용량·증가 시점. 좌석/활성 사용자·자동화 횟수·요청/실행 시간·CPU/메모리·저장 GB-월·전송 GB·백업·로그·외부 API로 분해
2. 비용: 고정료 + 항목별 실제 과금식(포함량·초과 단가·구간·최소 청구·올림) + 별도 지원/세금/환산 비용. 결제 주기·선결제·약정 확인, 월 환산액과 지급 시점별 현금 지출 분리
3. 운영 비용: 초기 구축·월 관리·장애 대응·이전 시간을 별도 표시. 시간 단가 미정이면 시간으로 유지, 현금 지출과 혼합 금지
4. 정상/최대/증가 시나리오를 같은 계약으로 비교. 순간 최대 부하를 한 달 내내 발생한 사용량으로 계산 금지
5. 월 상한과 대조. 초과 시 알림/거절/대기/축소/유료 전환의 사용자 효과·권한을 선택하고 재검토 시점 지정

- 묶음 가격에 포함된 DB·트래픽 등 중복 가산 금지. 무료 한도 만료·절전·콜드 스타트·호출 폭주·재시도 비용도 해당 조건에서 반영
- 예산 알림과 지출 차단 구별. 예산 이내라는 주장에는 청구식·같은 기간의 사용량·남은 불확실성 연결
- 계산은 추정, 공식 견적과 실제 청구는 별도. 선택을 바꾸는 성능·호환·복원 조건은 해당 환경의 최소 실행 후 판정
- 결론: 충족 스펙·현금/운영 비용·남는 책임·추천이 바뀌는 조건. 시험 후보 추천과 운영 도입 분리. 유료 자원·계약·이전은 남은 미확인과 실행 범위 설명, 선택·권한 확인 후 진행
