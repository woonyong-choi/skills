# 데이터 · 동시성

| 조건 | 구현 전 확정 | 필수 대조·차단 |
|---|---|---|
| 값·경계 | 타입·단위·범위·NULL·기본값·정밀도·시간대·인코딩·길이·직렬화 | 호출자/제공자의 같은 입력 의미. 문자/byte/저장 공간 혼용 금지 |
| 결과·정본 | 완전성·페이지/종료 신호·오류, 정본/색인/캐시 소유자·갱신/삭제 전파 | 빈 값·읽기 실패·잘린 결과 구분. 부분 변경 시 무변경/부분 성공/보상 계약 확인 |
| 저장 선택 | 관계·접근 패턴·성장·갱신·내구성·운영 조건 | 저장 가능 여부만으로 DB 확정 금지 |
| 스키마 이전 | 기존 데이터·신구 소비자·배포 순서·불가역 변환·복원 | 이전 데이터·혼합 버전 입력, 백업 존재와 복원 성공 구분 |
| 재전송·중복 | 요청 식별자 생성자·범위·수명·다른 내용·진행 중·실패 후 정책 | 같은 이벤트 재전송과 정상 반복 요청 구분. 내용 해시만으로 중복 삭제 금지 |
| 공유 효과 | 실행권·내용 일치·원자성 경계·외부 효과 불확실 상태 | 두 요청 교차 실행, 효과 후 기록 전 중단. 실행권 전 공유 파일·외부 효과 변경 금지 |
| 순서·버전 | 전체/대상별/무관, 오래된 응답·시계 차이·누락 처리 | 역전·지연·재시작 후 최신 상태·허용 순서 대조 |
| 읽기 뒤 쓰기 | 충돌 검출·재시도·덮어쓰기 | 두 요청이 같은 이전 값을 읽는 경우의 계약 대조 |
| 잠금·비동기 | 잠금 대상·획득 순서·해제, 상태 소유자·수명·완료 전달 | 대기·취소·오류·잠금 중 외부 I/O·화면 이탈·연속 입력 대조 |
| 재시도·큐 | 안전한 효과·오류 종류·상한·지연·중단, 큐 용량·소비 속도·재처리 | 응답 소실·반복 실패·불량 항목·밀림·종료 대조 |

- 중복 정책은 매번 실행/기존 결과/거절/상태 갱신 중 실제 업무 의미로 선택. “한 번 호출”, “한 번 효과”, “성공 기록” 구분
- 실행권 확보 전 요청별 격리 준비는 허용, 최종 반영과 분리. DB 제약·큐 보장으로 외부 효과의 정확히 한 번 보장 금지
- 응답 소실은 실패 확정 아님. 식별자로 실제 효과 조회·대조, 불명확한 결제·발송 등의 무조건 재실행 금지
- timeout만으로 교착 확정 금지. 소유자·대기 관계·진행 조건 확인. 프로세스 내 잠금을 다중 프로세스 보장으로 확대 금지
- 순차·동시·중단 후 재개 검사 분리. 겹칠 경로가 없다는 근거로만 동시 조건 제외
- 큐는 처리량 외 지연 허용·실패 격리·영속 대기 요구로도 판단. 작은 사용량을 중복·권한·정확성 생략 근거로 사용 금지
