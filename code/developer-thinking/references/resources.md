# 자원과 성능

| 적용 조건 | 해야 할 판단 | 예외 | 확인 방법 |
|---|---|---|---|
| DT-RESOURCE: 반복·큰 입력·성능·자원 상한 | 실제 경로와 예산으로 CPU·메모리·I/O·대기·외부 비용 구분 | 부하 근거 없는 성능 최적화 제외, 현재 실패·상한 위반은 조사 | 대표·경계·순간 부하에서 정확성과 자원·지연 함께 대조 |

## 먼저 정할 범위

- 평균·순간 최대·지속 시간·동시 실행·데이터 분포·결과 크기·느린 소비자 조건 확인. 총량 하나로 부하 성격 확정 금지
- 시간 구간: 대기·초기화·처리·외부 호출·전송·전체 완료 분리. 부분 지연 감소를 전체 개선으로 대체 금지
- 자원 상한: 요청·연결·풀·프로세스·복제본·전체 시스템 구분. 설정값·예약량·실사용량·관측 최고치 구분
- 지연·사용량 예산은 사용자 목적·운영 제약에서 도출. 임의의 대규모 목표·안전 여유 비율 강제 금지

## 경로별 비용

| 대상 | 확인할 것 | 선택에 필요한 근거 |
|---|---|---|
| CPU | 알고리즘·반복·직렬화·압축·복사·경합 | 실제 호출 경로·프로파일과 입력 크기 변화 |
| 메모리 | 장기 보관·요청별 버퍼·재할당 공존·결과·캐시·관리 정보 | 할당·해제 수명과 동시 요청 합산, 초과 직전 실패 |
| I/O | 요청 수·묶음 크기·순차/임의 접근·왕복·재전송 | 읽고 쓴 bytes·호출·지연과 정확한 대상 |
| 캐시 | 정본·키·범위·갱신·무효화·허용 오래됨·퇴출 | 적중률뿐 아니라 전체 지연·메모리·갱신 정확성 |
| 동시 처리 | 공유 상태·직렬 구간·외부 한도·동시 작업 수 | 처리량 증가와 요청당 비용·긴 지연·실패율 |
| 대기열·stream | 생산/소비 속도·버퍼 상한·취소·역압 | 누적 메모리·밀림·순서·완전성·느린 수신자 |

- 메모리 예산에 기존·새 버퍼가 함께 사는 구간, 결과 소유권이 호출자에게 넘어간 뒤의 수명 포함. 요청 예산을 프로세스 RSS 상한으로 확대 금지
- 할당·연결·큐 상한 초과는 대기/거절/분할/외부 저장 중 정책과 비용 선택. 조용한 잘림·일부 성공·무제한 재시도 금지
- 병목 이동 확인: 계산 개선 뒤 전송·잠금·저장이 지배할 수 있으므로 실제 완료 경로 재측정
- 캐시는 관측된 반복 비용과 최신성 요구가 맞을 때 후보. 사전 도입 금지, 동시에 무효화·재시작·폭주·민감 데이터 노출 비용 비교
- 캐시 없음도 복제 지연·snapshot·동시 갱신에 따라 최신성 미보장. TTL은 캐시 항목 수명이며 원본 대비 최대 지연은 채운 시점의 값·갱신·재삽입 경로까지 확인해야 성립하는 주장
- 언어 원인 판정 전 언어 규칙·컴파일러와 옵션·런타임과 할당기·자료 배치·알고리즘·OS와 장치·측정 방법 분리. 같은 언어의 대안 검토, 재작성 자동 시작 금지

## 측정 해석

- 비교 전 질문·기대 결과·반증 조건·고정 조건·반복·중단 기준 명시. 탐색 결과를 사전 가설처럼 소급 금지
- 의미·데이터·반환 결과·내구성·자원·초기 상태가 다른 비교는 차이를 밝히고 전체 우열로 확대 금지
- CPU cache·DB buffer·OS page cache 구분. 재시작만으로 모두 비었다고 판정 금지
- 0 또는 빈 지표는 계측이 작동하는 양성 대조·필드·단위·집계·스키마 확인. 샘플링 최고값을 실제 절대 최고치로 확정 금지
- 같은 함수라도 다른 조건의 결과를 잡음으로 단정 금지. 반복 원자료·측정 경로·동시 작업 확인
- bytes·문자·토큰·요금, 누적량·현재량·최대량, 직렬화 크기·전송·저장 크기 구분. 측정값에서 비용 절감으로 넘어갈 때 누락된 조건 설명
- 정확성·실패 복구를 줄인 속도 향상은 동등 개선 아님. 여러 변경의 합산 효과에서 개별 기여율 창작 금지
- 통과: 현재 예산에서 정확성·지연·자원을 확인하고, 다음 최적화를 시작할 관측 기준 제시
