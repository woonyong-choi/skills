# 일관성 검사 기준

`skill_check.py`는 원본 스킬만 검사한다. 설치 대상 탐색은 `install.py`와 같으며 실험 스냅숏과 테스트 fixture는 대상에서 제외한다. 출력은 기존 스킬별 위반 목록과 `total N`, `--json`은 종류별 개수와 `total`이다. 종료 코드는 통과 0, 위반 1, 입력 오류 2다.

| 검사 | 판정 기준 | 정본 |
|---|---|---|
| 머리와 절 | 우선순위 문구 일치, 범위 또는 기반 줄, 존재하는 조건부 참조, 제목 단계 생략과 같은 2단계 절 중복 금지 | [스킬 작성 형식](authoring.md) |
| description | 큰따옴표 한 줄, `때 … 사용.` 또는 `때 … 적용.`의 사용 조건, 다른 스킬 이름과 함께 적용 표현 금지 | [스킬 작성 형식](authoring.md) |
| 용어 | 용어 표의 금지어와 정확히 일치하는 낱말 또는 열거한 한국어 조사 결합 | repo-docs 용어 |
| 규칙 복제 | 서로 다른 스킬의 본문 목록 항목이 공백 정리와 끝 마침표 제거 후 완전히 일치 | 공통 규칙의 정본 하나 원칙 |
| 스크립트 인자·출력 | CLI의 파일 머리에 비어 있지 않은 `인자:`와 `출력:` 설명 | 이 문서 스크립트 형식 |
| 비용 주석 | 기존 비용 검사기의 외부 호출 경계와 위치 검사, cost·vars·basis 형식 | code-style 비용 주석 |

규칙 복제는 공백을 제외한 20글자 이상만 검사한다. `파일 설명 주석`처럼 규칙이 아닌 항목명과 짧은 정렬 지시를 별도 맥락의 동일 규칙으로 단정하지 않기 위한 보수적 길이 기준이다. 의미 유사도 점수는 사용하지 않는다. 표는 `금지`, `필수`, `우선`, `만 허용`, `만 사용`이 있는 전체 행만 비교한다. 코드 블록, 인용, 스킬 출처 표기와 Markdown 링크가 있는 참조 항목, 머리 목록, 공통 스크립트 위치 안내는 중복에서 제외한다. 각 스킬의 제목 단계와 상세 절 구성은 역할별로 달라질 수 있다.

용어는 repo-docs의 `용어` 표에서 읽는다. 검사 대상에 repo-docs가 없으면 용어 검사는 적용하지 않는다. 코드 블록, 인라인 코드, 링크 대상, 인용, 금지어를 정의하는 표 행은 제외한다. 조사 목록은 `은·는·이·가·을·를·의·와·과·에·로·도·만·부터·에서·처럼·보다·마다·이면·라면`이다. 합성어와 자유로운 활용은 수동 검토 대상이다.

## 스크립트 형식

스킬의 `scripts/` 아래 Python·JavaScript 파일을 검사한다. `test_` 파일과 캐시 폴더는 제외한다. Python의 모듈 최상위 `__name__` 실행 분기, JavaScript의 `process.argv` 사용을 CLI로 판정한다. Python은 모듈 docstring, JavaScript는 첫 import 앞 줄 주석에 아래 항목을 둔다.

```text
인자: 위치 인자와 선택 옵션, 필요한 실행 위치
출력: stdout·stderr·생성 파일과 종료 코드
```

이 검사는 설명 형식의 누락을 막는다. 모든 옵션과 실제 출력이 문서와 일치하는지는 CLI 시험과 검토로 확인한다. 라이브러리 모듈에는 CLI 설명을 요구하지 않는다.

비용 주석은 `time O(…), heap O(…), stack O(…)` 순서와 0이 아닌 `alloc·io·tokens` 선택 필드를 검사한다. 연속 주석 묶음 안의 `basis`는 `estimate` 또는 `measured {근거}`다. O 식에 쓰인 단일 영문 변수는 `vars`에 정의한다. 여러 글자 변수의 의미와 복잡도 정확성은 코드 검토 대상이다. 비용이 필요한 함수의 탐색·위치 검사는 code-style 검사기를 그대로 호출한다. 그 의존 스킬이 없으면 입력 오류로 실패한다.

## 확인 범위

기계 검사는 바꿔 쓴 중복 규칙, 의미 충돌, 다른 절의 조건·예외 차이, 비용 추산의 정확성을 증명하지 않는다. PR의 수동 확인 항목으로 보완한다. 위반을 없애려면 해당 규칙의 정본을 남기고 참조로 바꾸거나 형식을 수정한다. 현존 위반을 위한 파일별 면제 목록은 두지 않는다.
